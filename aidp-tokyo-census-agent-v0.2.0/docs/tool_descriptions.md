# ■ SQLツールのDescription

各SQLノードのDescriptionへ、該当する内容を貼り付けます。

## ● list_areas

```text
比較対象61市区町村の地域コード、正式名称、クラスタIDを返します。
自治体名から地域コードを確認するときに使用します。
町田市は今回の比較対象外です。
```

## ● get_area_metrics

```text
指定したarea_codeの2020年・2025年の指標、変化量、クラスタ所属とRun IDを返します。
地域の特徴説明や、2地域の比較に使用します。対象外のコードは0件です。
```

## ● rank_population_growth

```text
2020年から2025年の5年間の人口増減率が高い順に5地域を返します。
人口そのものの多さや人口増加人数のランキングではありません。
```

## ● find_similar_areas

```text
指定したarea_codeと似た変化パターンの5地域を返します。
人口増減率、単独世帯割合差、65歳以上割合差を標準化した距離です。
距離が小さいほど類似します。地理的距離ではなく、候補は他の60地域です。
```

## ● get_cluster_summary

```text
2つのクラスタの地域数と指標の単純平均を返します。
人口加重平均ではありません。年齢不詳率差は両年の値がある地域のみの平均です。
利用可能件数とNULL件数も確認してください。
```
