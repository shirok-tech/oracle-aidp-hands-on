# ■ 同梱データの由来と比較条件

`inputs/` は、ブログ第2回で保存した比較データと機械学習の実行メタデータを、第3回の再現用に同梱したスナップショットです。第3回で統計の公開サイトから取り直したデータではありません。第1回・第2回で扱った出典・定義・比較条件を引き継いでいます。

| ファイル | 内容 |
|---|---|
| `tokyo_changes.csv` | 61市区町村の両年の指標と計算済みの変化量 |
| `comparison_validation_snapshot.json` | 比較条件、定義、除外理由、出典Run ID |
| `run_metadata.json` | 第2回のAI Runとモデル設定、元の保存先記録 |
| `model_parameters.json` | 特徴量の順序、標準化スケール、クラスタ中心 |
| `profile_payload.json` | クラスタ所属地域と解釈上の注意点 |

CSVの元ファイル名は `part-00000-aa929a0e-861a-4c82-9551-6eeec2122ca5-c000.csv` です。配布時は `tokyo_changes.csv` としていますが、ファイル内容は変更していません。4つのJSONも提供された保存済みデータと同じ内容です。

CSVファイルのSHA-256：

```text
610d69f0687aa733aa09d3f2b747431a68964225d136c97cf634a24f3df1ba6f
```

JSON内の `source_sha256` などは、第2回で記録した別形式・別処理段階のハッシュです。このCSVのバイト列ハッシュと一致させるものではありません。JSON内の `/Volumes/...` は元環境の保存先記録で、リポジトリ内のダウンロードリンクではありません。

## ● 引き継ぐ条件

- 比較Run ID：`compare61_20261020_01`
- AI Run ID：`change_ml_20261020_01`
- 比較期間：2020年から2025年
- 入力対象62市区町村から、保存された境界変更の比較条件により町田市（13209）を除外し、61市区町村を使用
- クラスタ0：17地域、クラスタ1：44地域
- 年齢不詳率のNULLを保持

除外理由と参照URLは `comparison_validation_snapshot.json` の `excluded_reasons` に保存されています。人口・世帯・年齢の定義は `definitions`、特徴量の意味は `profile_payload.json` の `feature_definitions` で確認できます。元データの出典URLや利用条件を新たに推測して補ってはいません。

## ● 数値の扱い

人口増減率は5年間の割合（%）、世帯・年齢の割合差はパーセントポイント（pp）です。65歳以上割合の分母は年齢判明人口です。クラスタ平均は自治体ごとの単純平均で、人口加重平均ではありません。

本セットの検証は保存された数値・定義・Run間の整合性を確かめるものです。元の統計公開値の再監査、現在人口の確認、将来予測、因果推論は含みません。第三者データの出典・利用条件を、コードのライセンスと同一のものとして扱わないでください。
